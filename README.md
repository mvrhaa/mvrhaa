I'm Ruslan, a second-year Computer Science student at PJATK in Warsaw.

Most of what I build sits between security and data: an OSINT crawler that maps a site only inside the scope it is allowed to touch, a log watcher that flags brute-force SSH logins, and a banking REST API on Spring Boot with Spring Security. I also like quant problems, and I test every model against a plain baseline, for example how well three methods rebuild the euro area yield curve. With my team I won the Quantum Optimization track at IBM Qiskit Fall Fest 2026.
